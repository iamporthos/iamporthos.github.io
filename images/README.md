# Images — drop your files here

Name your files exactly as below (lowercase, .jpg). Until a file exists, the site
shows a styled placeholder with the expected filename, so nothing ever looks broken.

JPG is assumed, but if your file is a .png, just update the filename in
`js/projects.js` to match.

## Tips

- Timeline cards crop to 4:3 — landscape images work best there.
- Keep files under ~500 KB each for fast loading (export at ~1600px wide, 80% quality).
- The Mila video should be an .mp4, ideally under 20 MB (GitHub hard-caps files at 100 MB).
- Want more/fewer images on a project page? Edit that project's `images` list in `js/projects.js`.
